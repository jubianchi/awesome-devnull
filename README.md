# Awesome /dev/null [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of community projects built around [/dev/null](https://dev-null.sh), the social network for devs.

Since launch, nullers have built clients, editor plugins, browser extensions, libraries and more. This list collects
them in one place. Missing something? [Contribute](#contributing).

## Official

- [dev-null.sh](https://github.com/dev-null-sh/dev-null.sh) - Source code of the platform itself.

## Terminal clients

- [arhen/devnull-tui](https://github.com/arhen/devnull-tui) - Feed, threads and inbox in any terminal, or as a herdr pane.
- [eggplants/dev-null-tui](https://github.com/eggplants/dev-null-tui) - A TUI for dev-null.sh.
- [hampel/zero-dev-null](https://github.com/hampel/zero-dev-null) - Commit from the command line, signed with an SSH key on your GitHub account.
- [joseederangojr/stdout](https://github.com/joseederangojr/stdout) - TUI client written in Rust.
- [mihaidaniel34/dev-null-tui](https://github.com/mihaidaniel34/dev-null-tui) - TUI client for dev-null.sh.
- [negoziator/dev-null-herdr-plugin](https://github.com/negoziator/dev-null-herdr-plugin) - Post to /dev/null without leaving [herdr](https://herdr.dev).
- [razajahangir/devnull-tui](https://github.com/razajahangir/devnull-tui) - Terminal client built on the signed `/api/v1` API.

## Desktop and devices

- [dev-null-addict](https://github.com/cordx56/dev-null-addict) - Toggle a /dev/null window anytime you want.
- [dev-null-app](https://github.com/NativePHP/dev-null-app) - Native iOS and Android app, built with NativePHP.
- [devnull-tv](https://github.com/HelgeSverre/devnull-tv) - Samsung Tizen TV client built on the public API.
- [omarchy-devnull](https://github.com/zangetsu02/omarchy-devnull) - Unread badge, glance popup and keyboard-driven client for the Omarchy shell, drawn as a `git log --graph`.

## Editors and IDEs

- [slashnull.nvim](https://github.com/Allianaab2m/slashnull.nvim) - Commit, timeline, replies, stars and notifications from Neovim.
- [vs-dev-null](https://github.com/lucianofedericopereira/vs-dev-null) - Browse, follow and commit from VS Code and VSCodium.

## AI agents

- [claude-dev-null](https://github.com/jubianchi/claude-dev-null) - Claude plugin for /dev/null.
- [devnull](https://github.com/younes-io/devnull) - Claude Code goodies, including a `/screensaver` that sends your terminal to /dev/null.
- [devnull-claude-plugin](https://github.com/humunuk/devnull-claude-plugin) - Claude Code plugin for dev-null.sh.
- [devnull-wrapped](https://github.com/Renaissancexbt/devnull-wrapped) - Agents that post what you ship, wrapped cards, crew and README badges.

## Browser extensions

- [dev-null-plus-plus](https://github.com/aaqidmasoodi/dev-null-plus-plus) - Themes, AI rewrite, link previews, image peek, picture-in-picture and more.
- [dev-null-reactions](https://github.com/mrjf/dev-null-reactions) - Any-emoji reactions in Chrome and Helium, stored as Git commits.

## Libraries and SDKs

- [dev-null-api](https://github.com/ryohidaka/dev-null-api) - TypeScript client for the public, read-only API.
- [devnull-notifier](https://github.com/GromNaN/devnull-notifier) - Symfony Notifier bridge.
- [DevNull.Client](https://github.com/AngelMunoz/DevNull.Client) - .NET client and library.
- [devnull-stream](https://github.com/jubianchi/devnull-stream) - `devnull://` PHP stream wrapper: read, commit, reply, star and give pastéis with `fopen()`, `fwrite()` and `touch()`.

## Tools

- [dev-null-proxy](https://github.com/Seldaek/dev-null-proxy) - Local proxy so `https://dev/null` serves dev-null.sh and you can pipe to `/dev/NULL` to commit.
- [postslop](https://github.com/bangnokia/postslop) - Local social publishing for X, Bluesky and dev-null.sh.

## Themes

- [omarchy-dev-null-dark](https://github.com/fernandofreamunde/omarchy-dev-null-dark) - Dark Omarchy theme based on the dev-null.sh color scheme.
- [omarchy-dev-null-light](https://github.com/fernandofreamunde/omarchy-dev-null-light) - Light Omarchy theme based on the dev-null.sh color scheme.

## Media

- [dev-null-video-remotion](https://github.com/HelgeSverre/dev-null-video-remotion) - Launch film for dev-null.sh, drawn as a `git log` with Remotion.

## Websites

- [dev-null-pulls](https://dev-null-pulls.vercel.app/about) - A grown man vs. a random number generator, rolling for an open pull request on dev-null.sh ([announcement](https://dev-null.sh/@aaqidmasoodi/commits/01a169a8-d508-708c-abf3-1b81e6c35920)).

## Contributing

Contributions are welcome! To add a project, open a pull request that:

- adds one project per pull request, in the most fitting section;
- keeps entries in alphabetical order within their section;
- follows the format `- [name](link) - Short description.`, with the description ending with a period;
- links to a project that is publicly available and actually related to [/dev/null](https://dev-null.sh).

If no section fits, feel free to propose a new one.
